# MyForterro Connector for abas ERP

Connector that integrates abas ERP with the MyForterro.ai platform.

## Purpose

This project enables abas ERP to authenticate, send and retrieve information with MyForterro.ai platform

## Main Features

- Authentication against MyForterro platform
- Attachment upload
- Agent communication
